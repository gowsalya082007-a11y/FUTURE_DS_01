Business Sales Performance Analytics

Project Overview

This project analyzes sample business sales data using Microsoft Excel to understand sales trends, top-selling products, categories, and regional performance.

Tools Used

- Microsoft Excel
- Excel formulas
- Charts and dashboard

Key Insights

- Total Sales: ₹4,786,000
- Total Profit: ₹723,500
- Electronics is the highest-selling category.
- South is the top-performing region.
- Laptop and Mobile Phone are the leading products by sales.

Recommendations

- Focus on increasing Electronics sales.
- Improve sales performance in the East region.
- Promote Stationery products to increase sales.

Note

This project uses sample data created for learning and demonstration purposes.
